# Mi Portafolio Personal 🚀

![Portfolio Screenshot](/public/image/avatar1.jpg)

## 📋 Descripción

Portfolio personal desarrollado con **Next.js**, **Tailwind CSS** y **TypeScript**. Diseñado para mostrar mis proyectos, habilidades y experiencia como desarrollador web.

### 🎯 Características

- ✅ **Diseño moderno y responsivo** - Adaptado a todos los dispositivos
- ✅ **Modo oscuro/claro** - Experiencia personalizada
- ✅ **Proyectos destacados** - Grid interactivo con detalles
- ✅ **Formulario de contacto** - Funcional y visual
- ✅ **Optimizado para SEO** - Metadatos y rendimiento
- ✅ **Animaciones suaves** - Transiciones y efectos visuales

---

## 🛠️ Tecnologías utilizadas

| Tecnología | Descripción |
|------------|-------------|
| **Next.js 14** | Framework React con App Router |
| **Tailwind CSS** | Estilos utilitarios y diseño responsivo |
| **TypeScript** | Tipado estático y mejor desarrollo |
| **Heroicons** | Iconos modernos y escalables |
| **Font Awesome** | Iconos para redes sociales |
